Efficient Attention

Posted on 2017-10-16 In note , paper-reading Views:

好记性不如烂笔头。

概要

该文针对attention mechanism的计算性能提出一些优化措施。

Basic Attention Mechanism

Model

图中x为源端句子，y为目标端句子；源端使用RNN模型进行编码，目标端使用RNN进行解码；ht及st为中间隐层表示；⨁为上下文向量，记为ci。该向量通过源端状态加权得到：
ci = ∑jαijsj
αi = softmax(fatt(hi, s))
其中，fatt(hi, s)是根据源端及目标端的隐层状态表示计算相关度的函数。具体选取如下：
$$f_{att}(h_i, s_j) = \begin{cases} v_a^T\ \mathrm{tanh}(W_a [h_i, s_j]) &, \text{in [1]} \ h_i^TW_a s_j &, \text{in [2]} \end{cases} $$
其中，Wa与va是模型需要学习的关于对齐的参数。

Time Complexity

设|S|为源端句子长度，|T|为目标端句子长度，用D表示源端及目标端RNN的隐层状态维度大小。attention mechanism在目标端解码过程中，每生成一个字词，都需要计算一次c，而每进行一次计算都需要花费O(D2)的时间（维度为D × D的矩阵与D × 1）；也容易知道共进行了|S||T|次计算；所以总时间复杂度为O(D2|S||T|)。（文[2]中将fatt设定为两个向量相乘，被称为dot-based attention mechanism，此时的时间复杂度为O(D|S||T|)。）

Memory-Based Attention Model

Basic Model


在文[3]中，作者在编码过程的同时产生attention contextC ∈ ℝK × D；在解码过程中，解码器attention的不再是编码器的隐层状态，而是这些向量Ck：
$$\mathbf{C}_{k} = \sum_{t}^{\vert S\vert}\alpha_{tk}s_t$$
αt = softmax(Wαst)
$$c=\sum_{i=0}^{K}\beta_i\mathbf{C}_i$$
β = softmax(Wβh)
其中，Wα ∈ ℝK × D及Wβ ∈ ℝK × D是模型需要学习的参数。前两个式子描述的是编码过程，复杂度为O(KD|S|)；后两个式子描述的是解码过程，复杂度为O(KD|T|)；总复杂度为O(KD(|S|+|T|))。在实际操作中，D多为512或者1024；这让我们有机会将时间复杂度降低。

More Details

  1. 激活函数的选用：将softmax替换为sigmoid，并将后者称为scoring function，作用可以视为gates。
  2. 模型的解释：Ck可以视为attention context，编码过程中计算该矩阵，类似于动态规划中的笔记法；解码过程中的attention操作，则是根据解码的隐层状态选择合适的上下文。
  3. 位置编码：作者通过类似下图的函数将位置信息也编码进Ck中，目的是让C1, C2, ⋯更多的学到源端序列前面的信息，⋯, CK − 1, CK更多的关注后面的信息，而中间的矩阵更多关注中间的信息。
    $$\mathbf{C}^{PE}=\sum_{s=0}^{\vert S\vert}\alpha_{s}^{PE}h_s$$
    αsPE = softmax(Wαhs ∘ ls)
    其中，ls来自于如下的函数，图像如下：
    $$L_{ks}=(1-k/K)(1-s/\mathcal{S})+\frac{k}{K}\frac{s}{\mathcal{S}}$$
    上式中k ∈ 1, 2, ⋯, K是上下文向量的索引，𝒮是所有源端序列中最长长度。
