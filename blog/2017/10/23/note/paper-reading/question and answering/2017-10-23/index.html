Coarse-to-Fine Question Answering for Long Documents

Posted on 2017-10-23 In note , paper-reading , question and answering Views:

Skim and scan, more questions will be solved.

概述

长文本QA的扩展性因受限于RNN的建模能力及其难以并行的特征性能低下。本文受人类在进行阅读时活动的启发提出了模型：先大致浏览全文，再仔细阅读可能相关的部分，进而得出答案。该文的方法也同样分为两步：先用运行效率不错的模型进行句子选择(sentence selection)，再使用性能不错但运行缓慢的RNN进行答案生成(answer generation)。实验表明该模型在WikiReading数据集上性能不赖，速度还快了3.5 ∼ 6.7倍。
本文的亮点是想法直接，但是实现起来并不容易。作者在实验过程中使用distant supervision来将两步模型的训练独立开来；也尝试强化学习直接以任务的最终目标来训练前者。同时，为了凸显模型较以往模型的优势，选择数据集的过程也反映了作者的巧思。但同时该模型可能缺乏推理能力。

动机

传统解决文档上QA方法都是基于RNN的。但是RNN因为其只能顺序读取所有字符，而这些字符在长文档情形下可能多达上千个，运行效率低下；除此之外，基于RNN的模型同样也会对文档进行截断，这可能丢失信息。
受启发于人类的阅读过程：先浏览，找出相关内容；再详读，生成答案；本文提出了coarse-to-fine model。

模型

模型整体流程如上，sentences selection部分负责挑选出相关句子，步骤answer generation部分负责根据相关内容生成答案。值得注意的是问题的答案不一定在原文中出现过。

问题形式化

训练数据为问题-文档-答案三元组集合⟨x(i), d(i), y(i)⟩i = 1N，其中y是问题-文档(x, d)的答案。文档d是一些句子的序列 s1, s2, ⋯, s|d|。假定，答案可以从这些句子集合的自己中推断出来。

模型细节

模型分为两部分：

  1. 效率高的sentence selection：根据输入的问题x与文档d生成关于句子的分布p(s|x, d)
  2. 复杂精细的answer generation：根据问题y与文档表示(document summary)d̂生成答案

Sentence Selection Model

该组件的要求是高效，作者尝试了三种简单高效的模型：

  1. BoW Model
    hl = [BoW(x); BoW(sl)]
    vl = vTReLU(W hl)
    p(s = sl|x, d) = softmax(vl)
    其中，x为问题；sl为文档中的句子；BoW为得到词袋表示的函数，即将出现在句子序列中的词向量取均值；[;]是将向量拼接起来；W, v及词向量为模型参数。后两项式子就是通过简单的前馈网络得到句子上的概率分布。
  2. Chunking Model
    为了获得更加细粒度的信息，作者将每个句子sl按照定长切分为块序列cl, ii = 1J，之后使用于BoW Model相同的操作得到各个块上的概率分布。而句子层次上的分布通过下式得到，即积乘该句子分块的概率大小：
    $$p(s=s_l\vert x, d)=\sum_{j=1}^{J} p(c = c_{l, j}\vert x, d)$$
  3. Convolution Model
    先将问题x与句子sl拼接起来，后用F个宽度为w卷积核对该矩阵提取特征，最后进行最大值池化操作，得到句子的表示hl ∈ ℝF。之后将该表示输入到与BoW Model相同结构的前馈网络中得到概率分布。

Document Summary

之后将根据上述的概率分布得出文档的整体表示，采取了如下两种方式：

  1. Hard Attention
    在训练过程中，根据上述得出的概率分布随机抽取一个句子表示并作为该文档的表示：
    ŝ ∼ p(s|x, d)
    d̂ = ŝ
    在测试过程中，使用概率最大的那个句子作为该文档的表示。
    为了包含更多的信息，我们也可以随机抽取K个句子表示并拼接在一起作为文档的最终表示。
  2. Soft Attention
    该方法的过程如下：
    $$\hat{d}_m = \sum_{l=1}^{\vert d\vert} p(s=s_l\vert x, d) \cdot s_{l, m}$$
    其中，p(⋅)为sentence selection model输出的概率分布；sl, m是在第l个句子中的第m个词语（m ∈ 1, ⋯, M，M为最大长度，人为指定，超过截断不足补齐）。

hard attention更加灵活，没有把不同句子中的词语信息混合，但训练不易；而soft attention采用的方式直接，训练按照端到端进行即可。

Answer Generation Model

答案生成模块使用的是文[2]中的模型。该模型读入问题、文档并通过GRU编码，之后再通过另一个GRU生成答案。具体细节可以参见文[2]。

训练

本文的模型类型多样，故而采用了多种训练方式，如下：

  1. Distant Supervision
    为了获取训练sentence selection组件，作者采用了一些粗糙的启发式的标记规则：将包含答案的完整句子作为正确标记；若不存在则选择文档的第一句。之后就按照监督学习的方法最大化对数似然：
    J(θ) = log pθ(y,s|x, d)
     = log pθ(s|x, d) + log pθ(y|s,x)
    其中，$$y^_$$表示正确答案，s*表示正确的句子（也表示最终的句子表示）。
  2. Reinforcement Learning
    强化学习也是应对sentence selection过程中没有标记数据的方法。作者在此处将reward function定义为给定句子 sl 后选出正确答案 y 的可能性：Rθ(sl) = log pθ(y = y|sl, x)。并将目标函数定义为：
    J(θ) = ∑sl ∈ dpθ(s = sl|x, d) ⋅ Rθ(sl)
     = ∑sl ∈ dpθ(s = sl|x, d) ⋅ log pθ(y = y|sl, x)
    该目标函数的梯度通过多次随机采样（ŝ ∼ pθ(s|x, d)）的方式得出可能的句子。另外，为了应对强化学习不稳定的局面，作者还将上述的distant supervision及curriculum learning应用上了。
  3. Soft Attention
    这种情形下模型整体都是可微的，使用SGD算法即可优化，不再赘述。
