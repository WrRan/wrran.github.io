LeetCode - 0142 - Linked List Cycle II

Posted on 2017-07-22 In acm Views:

判断一个链表是否有环，若有则返回该环开始时的指针
(●ˇ∀ˇ●)

题目链接

LeetCode - 0141 - Linked List Cycle II

题目解析

这题比LeetCode - 0141 - Linked List Cycle更加巧妙，上题需要的只是定性分析，而该题需要定量分析。
用slow和quick分别指代慢指针与快指针，两者都从head开始往前走，slow每次走一步，而quick每次走两步。
假设经过t次操作后，两者相遇，我们来仔细看下两者的路程差：

如上图所示，将链表分为三段，head的对应结点o到环的开始结点A长度为x，环的长度为y，相遇时slow在环中的移动距离为z。
则有以下方程：
t = x + z
2t = x + y + z
将第一个式子代入到第二个中，得到：x = y − z。
由此，可以得出下述算法：

  1. 设置两个指针slow与quick
  2. slow与quick分别以一次一步和一次两步的节奏往前迈
  3. 在迈步过程中，quick若为NULL，则说明无环
  4. 当slow与quick相等时，说明存在环，此时将quick设置为head并以每次一步的步伐往前迈，同时slow仍旧按照一次一步的步伐往前迈，当两者相遇时，就得出了环的开始结点

复杂度分析

时间复杂度：O(n)
空间复杂度：O(1)
