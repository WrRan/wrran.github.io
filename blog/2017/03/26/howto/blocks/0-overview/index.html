模型描述

模型计算为
f(x; θ) = softmax(W(2)ReLu(W(1)x + b(1)) + b(2))
最外层的输出为softmax，加总之后总和为1，所以可以将其解释为概率分布：
f(x)c = p̂(y = c|x)
其中，输入x是一个784维的输入，种类c ∈ {0, ⋯, 9}

目标函数为
$$ l(f(\mathbf{x}), y) = - \sum_{c=0}^9\mathsf{1}_{(y=c)} \mathsf{log} f(\mathbf{x})_c = -\mathsf{log} f(\mathbf{x})_y $$
其中，1为指示函数。
为了防止过拟合，我们常常会加上正则化项。

优化算法选用SGD。
