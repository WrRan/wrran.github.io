记号

数据集

记号 含义
D 数据集
Dtrain 训练集
Dvalid 验证集
Dtest 测试集

注：验证集用来挑选模型及超参；测试集用来评估模型的泛化能力，并比较不同算法下模型的性能。

该教程大部分处理的是分类任务，所以数据集D是一系列数据对(x(i), y(i))。我们使用上标来区分训练集中不同的实例：x(i) ∈ RD表示的就是维度为D的第i个训练实例。相似的，y(i) ∈ 0, ⋯, L表示输入xi的标签。

数学符号

记号 含义
W 除非另有说明，否则就是指矩阵
Wij 矩阵W的第i行第j列的元素
Wi· 向量，矩阵W的第i行
Wi 向量，矩阵W的第j行
W·j 向量，矩阵W的第j列
b 除非另有说明，否则就是指向量
bi 向量 b 的第i个元素

其他

记号 含义
D 输入数据的维数
Dh(i) 第i层隐层表示的维数
f(x) *见注释
L 标签数
L(θ, D) 参数为θ的模型关于数据D的对数似然
l(θ, D) 参数为θ的预测函数f关于数据D的经验损失
NLL 负对数似然
θ 某个指定模型的所有参数

注：fθ(x)为模型P(Y|x, θ)的分类函数，定义为argmaxP(Y = k|x, θ)。实际使用中常常省略参数θ

实际实验时，往往会花费很长时间。及时保存模型就显得很重要啦。

别使用cPickle长期保存你的训练/测试函数
Theano中的function是兼容Python中的deepcopy/pickle机制的，但是不应当使用这些机制长期保存这些函数。因为Theano内部处在活跃发展阶段，保存函数之后可能就没法再次un-pickle。正确的打开方式是，使用这些机制来短期保存function。

更多详情，可以参见serialization in Theano或者Python’s pickling。

绘制中间结果

可视化有助于我们了解模型或者训练算法正在做什么。如果你有充足的硬盘空间，你的训练脚本可以保存这些中间模型，之后再使用可视化脚本处理这些被保存的模型。
那些可能有助于你可视化的库：Python Image Library与matplotlib。
