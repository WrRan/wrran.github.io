Blocks学习手册（七） - 配置Blocks

Posted on 2017-03-27 In howto , blocks Views:

Blocks is a framework that helps you build and manage neural network models on using Theano.

Configuration

Blocks允许使用YAML文件或者环境变量来配置。环境变量的优先级高于配置文件，配置文件的优先级又比默认配置高。

配置项

下面是Blocks支持的配置项。

default_seed

这个是用来设置随机生成器种子的，包括如Numpy中的RandomState和theano中的MRG_RandomStreams。这应当为整数，默认被设置为1。

recursion_limit

被用来设置递归层数，比如说MainLoop。另外一个常常被用到的就是用序列化或者反序列化一个复杂对象。

profile, BLOCKS_PROFILE

一个布尔值，告诉Blocks是否在MainLoop.run()之后打印出程序的性能信息。

log_dackend

用来存储实验日志的实体。默认被设置为python，它将日志存储为内存中的一个对象；另一个选项是sqliter。

sqlite_database, BLOCKS_SQLITEDB

指定将被用到的SQLite数据库文件。

max_blob_size

存储到SQLite数据库中的对象的最大位数。对象大小要是超过了该上限，将触发警告。默认是4 kilobyte。

temp_dir, BLOCKS_TEMPDIR

指定Blocks创建临时文件的文件夹。如果没有指定，则将根据平台信息选用Python库中的tempfile。

class blocks.config.ConfigurationError

当必需的配置项没有被设置时抛出的错误。
