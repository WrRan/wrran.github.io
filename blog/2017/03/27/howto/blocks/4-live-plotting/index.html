Blocks学习手册（五） - Live Plotting

Posted on 2017-03-27 In howto , theano , blocks Views:

Blocks is a framework that helps you build and manage neural network models on using Theano.

概述

数据可视化往往比日志更能帮助我们了解模型的训练过程。该博文就是介绍Blocks中的图形化扩展。

注意：使用该博文中的内容，需要实现安装blocks-extras。

Blocks使用了库Bokeh来绘制图片，更具体地说，其实是使用了Bokeh Plot Server。它是一个轻量级的服务器，当我们向其发送相关数据时，就可以实时的在浏览器上观察到绘图结果。
