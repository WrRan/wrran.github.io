概述

这份开源库的推荐列表已经看过很多次了，但没有仔细研读过，使用过的就更少了。不过，将这份资料列表展示在我的博客上。一方面了解C++的强大，一方面了解自己可能会涉及的领域。

框架

项目名称 简介
Apache C++ Standard Library 算法，容器，迭代器和其他基本组件的集合
ASL Adobe公司的C++开源库
Boost C++准标准库
BDE Bloomberg公司使用的开发环境
Cinder Cinder is a free and open source library for professional-quality creative coding in C++.
Cxxomfort Cxxomfort is a small, header-only library that backports to C++03 or C++11 some of the nifty C++11 and later goodies, including some proposals still in the works.
Dlib Dlib is a modern C++ toolkit containing machine learning algorithms and tools for creating complex software in C++ to solve real world problems.
EASTL EASTL stands for Electronic Arts Standard Template Library. It is an extensive and robust implementation that has an emphasis on high performance.
ffead-cpp Framework for Enterprise Application Development, c++ framework, c++ web framework, c++ application framework, c++ rest framework, c++ soap framework, c++ web sites,c++ web applications, c++ driven web development - c++
Folly An open-source C++ library developed and used at Facebook.
JUCE The JUCE cross-platform C++ framework.
libPhenom An eventing framework for building high performance and high scalability systems in C.
libSourcey C++11 evented IO libraries for high performance networking and media based applications
libU LibU is a multiplatform utility library written in C, with APIs for handling memory allocation, networking and URI parsing, string manipulation, debugging, and logging in a very compact way, plus many other miscellaneous tasks
loki Loki is a C++ library of designs, containing flexible implementations of common design patterns and idioms.
Reason 跨平台的框架，使开发者能够更容易地使用Java，.Net和Python，同时也满足了他们对C++性能和优势的需求。
ROOT ROOT is a modular scientific software framework. It provides all the functionalities needed to deal with big data processing, statistical analysis, visualisation and storage. It is mainly written in C++ but integrated with other languages such as Python and R.
STLport STL中具有代表性的版本
STXXL STXXL: Standard Template Library for Extra Large Data Sets
Ultimate++ Ultimate++ is a C++ cross-platform rapid application development framework
Windows Template Library Windows Template Library (WTL) is a C++ library for developing Windows applications and UI components.

数据库

项目名称 简介
hiberlite C++ ORM for SQLite
Hiredis Minimalistic C client for Redis >= 1.2
LevelDB LevelDB is a fast key-value storage library written at Google that provides an ordered mapping from string keys to string values.
MySQL++ MySQL++ is a C++ wrapper for MySQL’s C API.
RocksDB A library that provides an embeddable, persistent key-value store for fast storage.
SQLite SQLite is a self-contained, high-reliability, embedded, full-featured, public-domain, SQL database engine.

图形图像处理

项目名称 简介
CGAL CGAL is a software project that provides easy access to efficient and reliable geometric algorithms in the form of a C++ library.
GMTL GGT is a collection of tools implementing Graphics primitives in generalized ways. Using modern C++ template metaprogramming and generic programming paradigms, GGT is a fast and flexible base for any modern graphics project.
Boost.GIL Generic Image Library
CImg An easy-to-use, efficient, portable C++ library for image processing.
xdp CxImage is a C++ class that can load, save, display, transform images in a very simple and fast way.
FreeImage FreeImage is an Open Source library project for developers who would like to support popular graphics image formats like PNG, BMP, JPEG, TIFF and others as needed by today’s multimedia applications.
GDCM GDCM is an open source implementation of the DICOM standard. Digital Imaging and Communications in Medicine (DICOM) is a standard that governs this capability by specifying handling, storing, printing, and transmitting information in medical imaging.
ITK ITK is an open-source, cross-platform system that provides developers with an extensive suite of software tools for image analysis.
ImageMagick ImageMagick includes a number of ready-made interfaces. This makes it possible to modify or create images automagically and dynamically utilizing your favorite development platform.
VTK The Visualization Toolkit (VTK) is an open-source, freely available software system for 3D computer graphics, image processing, and visualization.

数学

项目名称 简介
FFTW This is the official repository for the FFTW Fourier transform library, version 3.x
GSL The GNU Scientific Library (GSL) is a numerical library for C and C++ programmers.
Armadillo Armadillo is a high quality linear algebra library (matrix maths) for the C++ language, aiming towards a good balance between speed and ease of use
Ceres Solver Ceres Solver is an open source C++ library for modeling and solving large, complicated optimization problems.
CML The CML (Configurable Math Library) is a free C++ math library for games and graphics.
Eigen Eigen is a C++ template library for linear algebra: matrices, vectors, numerical solvers, and related algorithms.

机器学习

项目名称 简介
Evolving Objects EO is a template-based, ANSI-C++ evolutionary computation library which helps you to write your own stochastic optimization algorithms insanely fast.
Caffe Caffe: a fast open framework for deep learning.
CCV C-based/Cached/Core Computer Vision Library, A Modern Computer Vision Library
mlpack mlpack is a scalable machine learning library, written in C++, that aims to provide fast, extensible implementations of cutting-edge machine learning algorithms.
OpenCV Open Source Computer Vision Library
shogun The Shogun Machine Learning Toolbox (Source Code)
GMP GMP is a free library for arbitrary precision arithmetic, operating on signed integers, rational numbers, and floating-point numbers.
